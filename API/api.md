# Plotter Protocol v1.0

## 1. Serial
- Baudrate: 115200
- Format: 8N1 (8 data bits, no parity, 1 stop bit)
- Flow control: None

## 2. Boot Banner
При старте МК отправляет одну строку. Хост должен подождать 2 секунды после открытия порта, очистить буфер и прочитать её.

Формат: `PLOTTER <ver> steps_per_mm=<N> travel=<X>,<Y> reset=<R> crash=<C>\n`
Пример: `PLOTTER 1.0 steps_per_mm=80 travel=24000,1600 reset=UNK crash=1`

Питон сверяет `steps_per_mm` и `travel`. Если не совпало - разрыв соединения.

## 3. Framing
- Кодировка: ASCII
- Конец строки: строго `\n` (0x0A). Символ `\r` (0x0D) игнорируется.
- Максимальная длина строки: 64 байта (включая `\n`).
- Регистр: только заглавные буквы (`G1`, не `g1`).
- Координаты: только целые числа (int32_t) в шагах. Дробные (`X1.5`) вызывают ошибку.
- Таймаут приема: если строка не закрылась `\n` за 200 мс, буфер очищается.
- Пустая строка: ответ `ok\n`.

## 4. Sync
Строгая синхронизация. Хост отправляет одну команду, ждет `ok\n`.
МК отправляет `ok\n` только после полного завершения движения или действия.
Питон должен рассчитывать таймаут ожидания динамически (длина G1 + скорость F).

## 5. States&Events [S&E]

### Sys(ki)

 - [SBOO]SYSBOOT - инициалиция, надо ждать.

 - [SFAU]SYSFAULT - аппаратный сбой(аварийная блокировка на физ. уровне, выходить только перезапустив полностью всю систеу).

 - [SALA]SYSALARM - програмный сбой(софт лок, чето неправильно с тем что прислали контроллеру, гкод и д, M999 чтобы выйти из него).

 - [SREA]SYSREADY - система прогрузилась, шаговые дурачки активны и ждут команд.

 - [SIDL]SYSIDLE - жесткий простой, ток не подается на шаговых дурачков ниче не происходит вообще.

 - [SSLP]SYSSLEEP - глубокий сон, выйти только физической кнопкой

 - [SMNT]SYSMNTNC - режим сервиса , не принимает гкод чтобы руками откалибровать и т.д

 - [SPAN]SYSPANIC - //UNUSED, по факту такое невозможно но по делу если будет то пиздец

 - [SPWR]SYSPOWER - brownout, просадка по питанию, увы, полный shutdown

 - [STHR]SYSTHERMAL - //UNUSED перегрев драйверов (если будут термисторы)

 - [SUNH]SYSUNHOMED - ЭТОТ ПАРЕНЬ БЕЗДОМНЫЙ (запретить ---> ***ВООБЩЕ*** <--- любые команды до заселения ВООБЩЕ СУКА АНТИ-BESDOMNIY ACTION НЕЛЬЗЯ НИКАК ЭТО БУКВАЛЬНО САМОЕ ВАЖНОЕ ТУТ)

 - [SFLT]SYSFAULTLATCHED - Защелкнувшаяся проблема, подай питание заново

 - [SBLD]SYSBOOTLOADER - режим обновления прошивки, принимает по юзб от сервера (.hex)

### Линк Ивенты

 - [LSEA]LINKSEARCH - МК слушает serial, ждет рукопожатие.

 - [LSYN]LINKSYNC - Синхра, Запрашивает тек состояние буфера и подтверджаетт готовность, только пото гкод прнимается.

 - [LACT]LINKACTIVE - Обычное состояние. Читает команды.

 - [LSTA]LINKSTALLED - Буфер переполнен. шлет команду wait

 - [LLOS]LINKLOST - перевод в [SALA]

 - [LMAC]LINKNACK - ошибка контрольный сумы питончик пашелка нахуй (просит передать пакет заново ТОТ ЖЕ ПАКЕТ ЗА - НО - ВО , ТОТ - ЖЕ, NOT ACKOWLEDGED)

 - [LFLW]LINKFLOWCTRL - аппаратное управление потоко если прог буфер забит , МК физически дергает ножку и питон остан. отправку

### Сост. Движения

 - [MHOM]MOTHOMING - поиск нуля (G28)

 - [MPRO]MOTPROBING - для автоуровня //UNUSED

 - [MJOG]MOTJOG - ручное управление по командам для дебага

 - [MACC]MOTACCEL - разгон, выч по кривой ускорения

 - [MCRU]MOTCRUISE - движение по постоянной

 - [MDEC]MOTDECEL - торможение до fullstop

 - [MHOL]MOTHOLD - пауза, торможение с сохранением позиционирования

 - [MTOC]MOTTOOLCHANGE - //UNUSED НЕИСПОЛЬЗУЕТСЯ

 - [MPRE]MOTPREP - МК получил буфер команд, просчитал и рассчитывает с какой скоростью попиздошить

 - [MCRN]MOTCORNERING - прохождение угла

 - [MPRK]MOTPARKING - парковка хули

 - [MSTL]MOTSTALL - //UNUSED пропуск шагов не знаю если у нас конечно драйвер не тупой (унаступой)

 - [MBKL]MOTBACKLASH - компенс люфта при смене направления холостит что выбрать зазор в ремне

### Инструмент
 
 - [TOUP] - перо up up 

 - [TDWN] - перо down down

 - [TSET] - ожидание после касания

 - [TERR] - ошибка пера сработал датчик касания либо просто залупа какая то в принтер попала не знаю ваще нахуй это тут



## 6. Core Commands
Все координаты абсолютные, в шагах.

- `G0 X<int> Y<int>\n` - Быстрое перемещение (перо поднято).
- `G1 X<int> Y<int>\n` - Линейное перемещение (перо опущено).
- `M3\n` - Опустить перо (включить соленоид).
- `M5\n` - Поднять перо (выключить соленоид).
- `G28\n` - Homing. Поиск концевиков, сброс координат в 0.
- `G92 X<int> Y<int>\n` - Установить текущие координаты без движения моторов.
- `M114\n` - Запрос текущих координат. Ответ: `X<int> Y<int>\n` (без `ok`).

## 7. Advanced Commands
- `F<int>\n` - Установить скорость подачи (шаги/сек).
- `M201 X<int> Y<int>\n` - Установить ускорение (шаги/сек²).
- `G4 P<int>\n` - Пауза в миллисекундах.
- `M400\n` - Ждать завершения буфера движений.
- `M112\n` - Emergency Stop. Мгновенный стоп, переход в ALARM.
- `$$` - Вывести текущие настройки.

## 8. Errors
Формат ответа: `error:<код> <текст>\n`
- 0x1: Out of bounds (soft limit)
- 0x2: Homing failed
- 0x3: Limit switch triggered during move
- 0x4: Unknown command
- 0x5: Bad parameter
- 0x6: Command invalid in current state
- 0x2: Emergency stop
