# Plotter Protocol v1.0

## 1. Serial
- Baudrate: 115200
- Format: 8N1 (8 data bits, no parity, 1 stop bit)
- Flow control: None

## 2. Boot Banner
При старте Нано отправляет одну строку. Хост должен подождать 2 секунды после открытия порта, очистить буфер и прочитать её.

Формат: `PLOTTER <ver> steps_per_mm=<N> travel=<X>,<Y>\n`
Пример: `PLOTTER 1.0 steps_per_mm=80 travel=24000,16000`

Питон сверяет `steps_per_mm` и `travel`. Если не совпало - разрыв соединения.

## 3. Framing
- Кодировка: ASCII
- Конец строки: строго `\n` (0x0A). Символ `\r` (0x0D) игнорируется.
- Максимальная длина строки: 64 байта (включая `\n`).
- Регистр: только заглавные буквы (`G1`, не `g1`).
- Координаты: только целые числа (int32_t) в шагах. Дробные (`X1.5`) вызывают ошибку.
- Таймаут приема: если строка не закрылась `\n` за 200 мс, буфер очищается.
- Пустая строка: ответ `ok\n`.

## 4. Sync
Строгая синхронизация. Хост отправляет одну команду, ждет `ok\n`.
Нано отправляет `ok\n` только после полного завершения движения или действия.
Питон должен рассчитывать таймаут ожидания динамически (длина G1 + скорость F).

## 5. Состояния

### Система

 -  SYSBOOT[SBOO] - инициалиция, надо ждать.

-   SYSSEGV[SSEG] - аппаратный сбой(аварийная блокировка на физ. уровне, выходить только 
перезапустив полностью всю систеу).

-  SYSALARM[SALA] - програмный сбой(софт лок, чето неправильно с тем что прислали контроллеру, гкод и д, M999 чтобы выйти из него).

-  SYSREADY[SREA] - система прогрузилась, шаговые дурачки активны и ждут команд.

 -  SYSIDLE[SIDL] - жесткий простой, ток не подается на шаговых дурачков ниче не происходит вообще.

 - SYSSLEEP[SSLP] - глубокий сон, выйти только физической кнопкой

 - SYSMNTNC[SMNT] - режим сервиса , не принимает гкод чтобы руками откалибровать и т.д

 - SYSPANIC[SPAN] - ПИЗДЕЦ

### Сост. Связи

-   LINKSEARCH[LSEA] - нано слушает serial, ждет рукопожатие.

-     LINKSYNC[LSYN] - Синхра, Запрашивает тек состояние буфера и подтверджаетт готовность, только пото гкод прнимается.

-   LINKACTIVE[LACT] - Обычное состояние. Читает команды.

-  LINKSTALLED[LSTA] - Буфер переполнен. шлет команду wait

-     LINKLOST[LLOS] - Таймаут, если хост молчит во времмя движения - [SALA]

### Сост. Движения

-     MOTHOMING[MHOM] - поиск нуля (G28)

-    MOTPROBING[MPRO] - для автоуровня //UNUSED

-        MOTJOG[MJOG] - ручное управление по командам для дебага

-      MOTACCEL[MACC] - разгон, выч по кривой ускорения

-     MOTCRUISE[MCRU] - движение по постоянной

-      MOTDECEL[MDEC] - торможение до fullstop

-       MOTHOLD[MHOL] - пауза, торможение с сохранением позиционирования

- MOTTOOLCHANGE[MTOC] - //UNUSED НЕИСПОЛЬЗУЕТСЯ




## 6. Core Commands
Все координаты абсолютные, в шагах.

- `G0 X<int> Y<int>\n` - Быстрое перемещение (перо поднято).
- `G1 X<int> Y<int>\n` - Линейное перемещение (перо опущено).
- `M3\n` - Опустить перо (включить соленоид).
- `M5\n` - Поднять перо (выключить соленоид).
- `G28\n` - Homing. Поиск концевиков, сброс координат в 0.
- `G92 X<int> Y<int>\n` - Установить текущие координаты без движения моторов.
- `M114\n` - Запрос текущих координат. Ответ: `X<int> Y<int>\n` (без `ok`).

## 7. Advanced Commands
- `F<int>\n` - Установить скорость подачи (шаги/сек).
- `M201 X<int> Y<int>\n` - Установить ускорение (шаги/сек²).
- `G4 P<int>\n` - Пауза в миллисекундах.
- `M400\n` - Ждать завершения буфера движений.
- `M112\n` - Emergency Stop. Мгновенный стоп, переход в ALARM.
- `$$` - Вывести текущие настройки.

## 8. Errors
Формат ответа: `error:<код> <текст>\n`
- 0x1: Out of bounds (soft limit)
- 0x2: Homing failed
- 0x3: Limit switch triggered during move
- 0x4: Unknown command
- 0x5: Bad parameter
- 0x6: Command invalid in current state
- 0x2: Emergency stop
